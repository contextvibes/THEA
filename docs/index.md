# Project Documentation Index

## 1. Philosophy: Documentation as a Tool for Thought

This document is the central index for our project's knowledge base. Its purpose
is to provide a clear, at-a-glance overview of our documentation and to make the
process of creating new documents as simple as possible. We treat documentation
not as an afterthought, but as a tool for clarifying our thinking before and
during the work.
